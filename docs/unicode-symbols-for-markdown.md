# Unicode Symbols for Markdown Documentation

This reference provides commonly used Unicode symbols that enhance the readability and visual appeal of markdown documents.

## Status & Validation Symbols

### Check Marks & Status
- ✅ Heavy check mark (U+2705) - Working/Completed/Yes
- ☑️ Ballot box with check (U+2611) - Enabled/Selected  
- ✔️ Check mark (U+2714) - Confirmed/Validated
- ❌ Cross mark (U+274C) - Failed/Error/No
- ❎ Negative squared cross mark (U+274E) - Disabled/Cancelled
- ⚠️ Warning sign (U+26A0) - Warning/Caution
- 🚫 No entry sign (U+1F6AB) - Prohibited/Blocked
- ⭕ Heavy large circle (U+2B55) - Important/Highlighted
- 🔴 Red circle (U+1F534) - Critical/Stopped
- 🟡 Yellow circle (U+1F7E1) - Warning/In Progress
- 🟢 Green circle (U+1F7E2) - Success/Running
- 🔵 Blue circle (U+1F535) - Information/Default

### Progress & Development
- 🚧 Construction (U+1F6A7) - Under development/Work in progress
- 🔄 Counterclockwise arrows button (U+1F504) - In progress/Updating
- ⏳ Hourglass with flowing sand (U+23F3) - Pending/Waiting
- ✨ Sparkles (U+2728) - New/Enhanced/Featured
- 🎯 Direct hit (U+1F3AF) - Target/Goal/Objective
- 📋 Clipboard (U+1F4CB) - Todo/Checklist
- 🏁 Chequered flag (U+1F3C1) - Completed/Finished

## Arrows & Navigation

### Directional Arrows
- ➡️ Right arrow (U+27A1) - Next/Forward/Right
- ⬅️ Left arrow (U+2B05) - Previous/Back/Left

- ↙️ Down-left arrow (U+2199) - Return/Back down
