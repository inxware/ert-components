MQTT Publish Typed Misc ↓ Params ↓ Ports ↓

The MQTT Publish Typed block publishes a typed numeric or boolean value to an MQTT topic. Unlike the standard MQTT Publish block it accepts integer, float, and boolean input ports and converts the connected value to a string payload automatically.

Connect only one of value_i, value_f, or value_b. If more than one is connected the priority order is integer > float > boolean.

The Quality Of Service (QOS) level is an integer with three possible values: At Least Once (0), At Most Once (1), and Exactly Once (2).
