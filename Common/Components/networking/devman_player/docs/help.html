DevmanPlayer

This component provides contact with a devman server to enable the exchange of playlists and player status information. The component detects new playlists made available on the devman server, downloads them and notifies the application that it is available and where it is stored. The function block is not playlist format aware and does not parse the playlists to identify tracks that need to be downloaded. This Function block is neither responsible for downloading content references in the playlist. This is done by the playlist manager in conjunction with a downloader function block.

Devman Server Commands

The Devman server can issue the following commands (in XML format) to the application:

  • mediaSrcURL - updates the base URL where media is downloaded from. (persistently stored to configs/devman-player/MediaSrcUrl.cfg)
  • playlist - is the name of the playlist to play. This can be a fully qualified URL or just a path/filename that is appended to mediaSrcURL if no domain is provided. (persistently stored to configs/devman-player/PlayListURL.cfg)
  • NewDevmanPlayerURL - Add the priority devman server URL. This will add a new devman server to the top of the list. The previous server name will remain in the list. new
  • RemovePlaylist - Identifies a list of media paths to delete. The format of the path is currently devman server-specific.
  • RemoveOldContent - Signal that "old" content can be removed. The definition of old is defined by the application.
  • RemoveAllContent - Signal that all content should be removed.
  • Override_Content_Directory - Signal that a specific track should be played, which should override any currently playling track. (e.g. announcements). A URL (or local path) will be provided by Devman.
  • Set_Playmode - playmodes are application specific enumerated modes. e.g. 0 - mute, 1 - play constant, 2 - play from playlist. (persistently stored to configs/devman-player/PlayMode.cfg)
  • SetPlayerParameters->nVolume - updates the volume that the device should play media. It is application specific if this volume is managed by specific players or the overall system volume. (persistently stored to configs/devman-player/Volume.cfg
  • SetPlayerParameters->channels - updates the number of channels that should be used (e.g. stereo or mono mode). It is application/player specific how this would be handled. (persistently stored to configs/devman-player/Channels.cfg
  • state Controls the overall audio state of the device e.g. audio muted or not muted. It is application specific how to implement mute/unmute functionality. configs/devman-player/Mute.cfg

Ports

  • [In] Activate:
    Starts the Devman client polling the server to provide return path data and to check for updates.

  • [Out] Activate ------------:
    Signals Devman is active

  • [In] De-activate:
    Stops the device polling the Devman Server to send status information and/or receiving new messages

  • [Out] ------------: De-activation complete

  • [In] Set url:
    This will change the Devman sever URL that is polled. This change only persists while the application is running. It is not persisted after restart. This would need to be done directly by editing the devman/config/server file.

  • [In] URL:
    URL in standard URI format, including specific end-nodes.

  • [Out] URL:
    Output of the Devman URL, which can be set from the Devman server as well as the application.

  • [In] Config:
    Set playlist path and devman polling rate.

  • [In] plylst path:
    Deprecated: Playlist path is not currently supported in Devman. Applications can choose their own local paths for playlists.

  • [In] update rate:
    Time in seconds between Devman server polls.

  • [In] track info:
    Set the media meta-data to report back to Devman.

  • [In] playlist:
    Confirm the currently active playlist to Devman.

  • [In] player mode:
    Current track/video index in the playlist that is reported in the Devman Portal.

  • [In] curr. media:
    Currently playing track/video name that is reported in the Devman Portal.

  • [In] start time:
    The time at which the current media started to play that is reported in the Devman Portal.

  • [In] media duration:
    Report the duration the current track should play for.

  • [Out] new playlist:
    A new play list is published from Devman

  • [Out] plylst URL:
    New playlist URL published from Devman.

  • [Out] X-playlist:
    Playlist filename extracted from the full playlist URL. This does not include any preceeding path directories.

  • [Out] media/ URL:
    New media base URL published from Devman.

  • [Out] media /path:
    Local Path to media base. This is extracted from the above full media URL by removing the URI domain.

  • [Out] rem. list:
    Signal from Devman to remove specific list of content files.

  • [Out] files:
    list of content files from Devman to remove. The format of the list is not defined. Reference to the local root path of playlist of media files maybe indicated in a proprietary way depending on the media server implementation.

  • [Out] rem. unused:
    Signal from Devman to remove "old" files, as defined by the application.

  • [Out] rem. all:
    Signal from Devman to remove all media files. (i.e. typically everything under ./media/*).

  • [Out] Override:
    Signal from Devman to play an override media clip.

  • [Out] track url:
    Optional URL from Devman of the override media clip to play.

  • [Out] media parms:
    New media player parameters are available from the Devman Server

  • [Out] volume:
    volume in % (0-100) has been set by Devman Server

  • [Out] channels:
    Number of audio channels to play (typically 2 for stereo)

  • [Out] set mute:
    Mute state has been changed from Devman.

  • [Out] on/off:
    Mute state (true for mute).

  • [Out] status:
    Devman Server status has changed.

  • [Out] state:
    Devman Server state (Note: currently this is always 0 irrespective of server request errors and status).

  • [In] player state:
    Media player status to report back to Devman. 0 - mute, 1-playing, 2 - paused, 3 -error.

  • [Out] Raw XML:
    String containing the RAW XML from the Devman Server.

    Max Value:

    Default Value:
