MQTT Client Misc ↓ Params ↓ Ports ↓

The MQTT Client function block allows a connection to an MQTT broker, enabling the client to send and receive messages using the MQTT protocol. The client can be configured with various parameters, including the broker URL, port, client ID, username, and password. It also supports secure connections with TLS, providing the ability to specify certificates and keys for secure communication. The function block provides events for connecting and disconnecting from the broker and can handle errors during these operations.
