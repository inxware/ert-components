Samples radio signal quality, connection-evaluation metrics and data counters.

A read-only companion to the modem manager. Trigger Read to sample everything at once; every output is refreshed together so they describe the same instant.

The connection-evaluation group (TX power, repetitions, pathloss, energy estimate) comes from a single modem query that is only valid while registered. Check evalOk before trusting those five - when it is false they hold no meaningful value rather than a zero reading.

Values that the modem cannot supply are reported as an invalid sentinel rather than 0, so that 'no measurement' is never mistaken for 'measured zero'.

Read Sample all radio and counter values into the outputs below.
ResetCounters Zero the TX / RX byte counters. Does not affect the radio measurements.
Data Out
RSRP Reference Signal Received Power in dBm. Typically -140 (worst) to -44 (best); better than -100 is comfortable.
RSRQ Reference Signal Received Quality in dB. Roughly -20 (worst) to -3 (best).
SNR Signal to noise ratio in dB.
CELevel Coverage Enhancement level, 0-3. Higher means the modem is repeating transmissions harder to be heard, which costs power and throughput.
TXPower Current uplink transmit power in dBm. Valid only when evalOk is true.
TXReps Uplink repetitions the modem expects to need. Valid only when evalOk is true.
RXReps Downlink repetitions expected. Valid only when evalOk is true.
DLPathloss Estimated downlink path loss in dB. Valid only when evalOk is true.
Energy Modem's relative estimate of the energy cost of sending data now. Valid only when evalOk is true.
evalOk True when the connection-evaluation group above holds valid data. Check this first.
TXBytes Bytes transmitted since boot or the last counter reset.
RXBytes Bytes received since boot or the last counter reset.
Out Ev.
Done Fires once all outputs have been refreshed.
RDone Fires once the byte counters have been zeroed.
