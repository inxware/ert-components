Connect to a Wi-Fi access point

The device works as a Wi-Fi station to connect to an access point. This function block supports WPA2-PSK, open network and WPA2/3-Enterprise.

Ports Top ↑ Misc ↓ Params ↑
In Ev.
Connect Connect to Wi-Fi Access Point.
Disconnect Disconnect to the Wi-Fi Access Point.
Data In
type Wi-Fi authentication type. 0 for Password authentication, 1 for open network, 2 for WPA2/3-Enterprise network.
SSID The SSID of the Wi-Fi Access Point to connect to.
PSKPass The password of the Wi-Fi Access Point when type is WPA-PSK (type=0).
EntType Enterprise Network authentication type.0 for WPA2-Enterprise, 1 for WPA3-Enterprise, 2 for WPA3-192bit-Enterprise.
EAP The Extensible Authentication Protocol to be used to pass the authentication information. Only valid if type=2. 0 for TLS, 1 for PEAP, 2 for TTLS.
TTLS2 EAP's TTLS second stage connection method. Only valid if type=2 and EAP=2. 1 for MSCHAPV2, 2 fo MSCHAP, 3 for PAP and 4 for CHAP.
needCert Whether to validate the servers' certificate using CA cert. Only valid if type=2.
serverCert The CA cert to validate the servers' certificate. Only valid if type=2 and needServerCert=1.
tlsCert TLS client certificate. Only valid if type=2 and EAP=0.
tlsKey TLS client key if EAP method is TLS. Only valid if type=2 and EAP=0.
eapID ID for EAP authentication. Most of time, it is email address. Only valid if type=2.
eapUser Username for EAP authentication. Only valid if type=2.
eapPass Password for EAP authentication. Only valid if type=2.
Data Out
ipAddr Assigned IP Address after connection
RSSI The RSSI of the Access Point.
AP_MAC The MAC Address of the Access Point that this device is connected to.
errCode The error code when connection failed. Returns 0 if OK.
Reason The code to represent the disconnect reason. Returns 0 for manual disconnection.
Out Ev.
CDone The connection parameters are successfully passed into connection thread.
OK The device is connected to the Access Point.
Fail The device fails to connect to the Access Point.
DDone The disconnection request is sent to the internal thread.
Disconnected The device disconnects from the Access Point.
