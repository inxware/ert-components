eSIM Profiles Misc ↓ Params ↓ Ports ↓

Lists, reads, enables, disables and deletes the profiles already on an eSIM.

Every operation in this block is local. These are GSMA ES10c commands exchanged directly with the eSIM chip, so none of them needs a network of any kind - not cellular, not IP. That makes the block usable on a factory line with no connectivity, to select and verify the right profile on a device whose profiles were loaded during manufacture.

Local profile management is common to SGP.22 and SGP.32 - it is not specific to either, which is why this block is not named after a provisioning standard. Downloading a NEW profile is the one operation that needs a server, and it lives in the separate SGP.32 Download block.

Requires an eSIM chip. No currently supported target has one populated, so every operation reports not-supported (errCode 13) until eSIM hardware is available.

Ports Top ↑ Misc ↓ Params ↑
In Ev.
ListProfs Count the profiles installed on the eSIM.
GetProfile Read the details of the profile at the given index.
Enable Make the profile with the given ICCID the active one.
Disable Deactivate the profile with the given ICCID, leaving NO profile enabled.
Delete Permanently remove the profile with the given ICCID.
Data In
index Zero-based index of the profile to read, valid up to profileCount - 1.
ICCID ICCID of the profile to enable.
ICCID ICCID of the profile to disable.
ICCID ICCID of the profile to delete. Deletion cannot be undone - the profile must be downloaded again, which needs a server and usually a fresh activation code.
Data Out
profCount Number of profiles installed, or -1 when it cannot be determined (no eSIM). -1 is not the same as 0 - zero would mean an eSIM present but empty.
errCode Reason the listing failed. See the enumeration at the foot of this table.
profICCID ICCID of the profile read. Empty on failure rather than stale from a previous read.
profName Human-readable name of the profile read.
isEnabled True when the profile read is the currently active one.
errCode Reason the read failed. See the enumeration at the foot of this table.
errCode Reason the enable failed. See the enumeration at the foot of this table.
errCode Reason the disable failed. See the enumeration at the foot of this table.
errCode Reason the delete failed. See the enumeration at the foot of this table.
Out Ev.
LDone Fires when a count was obtained.
LFail Fires when the count could not be determined; profileCount reads -1.
GDone Fires when the profile was read.
GFail Fires when the index is out of range or no eSIM is present.
NDone Fires when the profile was enabled. The link will have dropped and be re-attaching on the new subscription.
NFail Fires when the profile could not be enabled.
BDone Fires when the profile was disabled. The device now has no subscription until one is enabled.
BFail Fires when the profile could not be disabled.
XDone Fires when the profile was deleted.
XFail Fires when the profile could not be deleted.
