SIM Manager Misc ↓ Params ↓ Ports ↓

Reports SIM state and identity, and switches between SIM types where the hardware allows.

Covers all three SIM flavours - physical SIM, SoftSIM and eSIM - behind one block. Which of them actually exist, and which can be switched to at runtime, differ per board and are reported separately by availableTypes and selectableTypes. A type can exist but not be selectable - an eSIM sitting behind a card-detect autoswitch is chosen by hardware, not by software.

Trigger Read from the modem manager's Connected event, not from app start. ICCID and IMSI are read from the SIM itself and need the modem initialised; reading at app start returns empty strings.

PIN entry gets exactly one attempt, by design. There is no retry anywhere in this block or below it, and entry is refused outright when only one attempt remains. Three wrong PINs require a PUK from the operator to recover, and no automatic behaviour is worth that risk.

In Ev.
Read Sample SIM state and identity into the outputs below. Trigger this after the link is up.
SelectType Switch to the SIM type on simType. Fails unless that type is in selectableTypes. A successful switch drops the link and re-attaches on the new SIM.
EnterPin Submit the PIN on the PIN input. One attempt only.
Data In
simType SIM type to select: 0 SIM, 1 SoftSIM, 2 eSIM. When unconnected the preferredType parameter is used.
PIN The PIN to submit. Never retried automatically.
Data Out
simState 0 Absent, 1 PIN required, 2 PUK required, 3 Ready, 4 Failed, 5 Unknown. Ready is the only good value.
activeType SIM type currently in use: 0 SIM, 1 SoftSIM, 2 eSIM.
availableTypes Bitmask of types present on this board: bit 0 SIM, bit 1 SoftSIM, bit 2 eSIM.
selectableTypes Bitmask, same bit order, of the types software can actually switch to. Always a subset of availableTypes.
ICCID Integrated Circuit Card ID of the active SIM. Read from the SIM, so needs the modem up.
IMSI International Mobile Subscriber Identity. Read from the SIM, so needs the modem up.
pinAttemptsLeft Attempts remaining before the SIM locks. -1 means the modem does not report it - treat unknown as 'do not risk an attempt', never as 'plenty left'.
errCode Reason for the last failure. See the enumeration at the foot of this table.
Out Ev.
Done Fires once the outputs have been refreshed.

SFail Fires when the type is not runtime-selectable on this board, or does not exist.

PFail Fires when the PIN was rejected, none was supplied, or PIN entry is not supported on this target. Not retried.
