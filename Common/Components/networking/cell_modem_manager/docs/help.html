Cell Modem Manager Misc ↓ Params ↓ Ports ↓

Brings the LTE-M / NB-IoT link up and down, and reports modem and network identity.

Owns the cellular connection. Triggering Connect starts an attach and returns immediately - an attach takes seconds on LTE-M and can take tens of minutes on NB-IoT, so the outcome arrives later on Connected or Failed, not on CDone.

The identity outputs (operator, MCC/MNC, cell ID, band) are only meaningful once the link is up, which is why they live on this block rather than a separate info block: an app would otherwise have to know when a separate block's data became valid.

Connected, Failed and Disconnected are driven by an internal monitor thread and fire asynchronously, independently of any function you trigger. PSM sleep is deliberately NOT reported as a disconnect - the modem is still registered and data resumes on wake.

In Ev.
Connect Start an attach using the current APN and RAT settings. Returns immediately; watch Connected / Failed for the outcome.
Disconnect Detach and release the PDN context.
Set Apply the APN / RAT values presented on the data inputs. Settings take effect on the next Connect - changing RAT on a live link would drop it.
ReadInfo Sample modem and network identity into the Data Out ports below. Only meaningful once online.
Data In
APN Access Point Name. Leave empty for network-assigned, which is correct on most modern networks and on pre-activated IoT SIMs.
APNUser APN username, when the operator requires PAP/CHAP authentication. Usually empty.
APNPass APN password. Usually empty.
RAT Radio access technology to use on the next connect: 0 leave modem default, 1 LTE-M, 2 NB-IoT, 3 both.
Data Out
state Connection state: 0 Idle, 1 ModemInit, 2 SimWait, 3 SimPinRequired, 4 SimFailed, 5 RadioOn, 6 Searching, 7 NoCoverage, 8 RegDenied, 9 Registered, 10 Online, 11 PsmSleep, 12 Reconnecting, 13 Disconnecting, 14 Failed.
regStatus Network registration status as reported by the modem.
ipAddr IP address assigned to the PDN context. Empty when not online.
isRoaming True when registered on a visited network rather than the home network.
activeRAT The RAT actually in use once attached: 1 LTE-M, 2 NB-IoT.
failReason Why the last attempt failed. See the enumeration at the foot of this table.
IMEI Modem IMEI. Answered by the modem itself, so readable as soon as the modem is up.
Operator Registered operator name.
MCC Mobile Country Code of the serving network.
MNC Mobile Network Code of the serving network.
CellID Serving cell identifier.
TAC Tracking Area Code.
Band LTE band number in use.
ModemFW Modem firmware version string.
errCode Reason the first failing identity read failed, or 0 when all succeeded. Lets an empty IMEI / Operator / ModemFW port be told apart from a read that never worked - an empty string with err_code 0 means the modem genuinely has nothing to report. See the enumeration at the foot of this table.
Out Ev.
CDone Fires immediately after Connect is accepted. This is NOT 'connected' - it only means the request was taken.
DDone Fires once the disconnect request has been issued.
Connected Asynchronous. Fires when the link reaches Online (or PSM sleep, which still counts as online).
Failed Asynchronous. Fires on a terminal failure - see failReason for which.
Disconnected Asynchronous. Fires when an established link is lost and the state machine begins reconnecting.
SDone Fires once the APN / RAT settings have been stored.
IDone Fires once the identity outputs have been refreshed. Fires even on a partial read - the ports that did resolve are still valid, and err_code says whether anything was missed.
