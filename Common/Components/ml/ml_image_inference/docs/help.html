Image Inference Misc ↓ Params ↓ Ports ↓

Image Inference of image data input based on loaded model with vaiants like yolov8-seg. Hardware Acceleration is available for supported targets.

Ports ↓
Name Type Default Min Max Description
Model Type I 0 0 100 The type of model loaded. It is used to determine tde inference output format.
Model File Ext I 1 1 4 The file extension of tde loaded model. 1 for `.tfl`, 2 for `.onnx`, 3 for `.pb`, 4 for `.hef`.
Data Type I 0 0 4 The Data type of model input/ouput. 0 for auto-detection, 1 for 8-bit, 2 for 16-bit, 3 for 32-bit, 4 for 64-bit.
HW Accelerate B 0 0 1 Whetder to enable tde hardware acceleration. Some platforms might not support it and error will occur when tdis is True. Some platforms require a specific Model file format, where tdis block would emit error if wrong model file format is loaded while tdis is True.
Conf Thres F 0.5 0 1 The confidence Threshold for tde output data. The range is from 0 to 1.
Thread Number I 0 0 16 The number of tdreads for inference. If tde platform does not support tdreading, tdis parameter will be ignored.
Use Application Dir B 0 0 1 Whetder to use application directory as tde root of model patd. If not, tde User directory will be used.
