TensorFlow Lite Micro Misc ↓ Params ↓ Ports ↓

TensorFlow Lite Micro runs machine learning models in memory-constrained environments, requiring only a few kilobytes of RAM. Load the model once with the load event, then repeatedly invoke inference with the do event. Input data is provided as a string via the data port and results are returned as a string on output, with an integer class or regression value on class/regression.

Ports Top ↑ Misc ↓ Params ↑
In Ev.
load Trigger model loading. Provide the model file path via model before firing this event.
do Run inference. Input data is taken from data. Fires -- on completion.
Data In
model Path to the TensorFlow Lite Micro model file. Consumed by the load event.
data Input data for inference, encoded as a string. Consumed by the do event.
Out Ev.
-- Fired when the model loads successfully.
err Fired when the model fails to load. Check errno for the error code.
-- Fired when inference completes. Results are available on output and class/regression.
Data Out
errno Error code from the most recent load attempt. Valid after the err event fires.
output Inference result as a string. Format depends on the model_type parameter. Available after the -- inference event fires.
class/regression Integer result representing the predicted class index or regression value. Available after the -- inference event fires.
