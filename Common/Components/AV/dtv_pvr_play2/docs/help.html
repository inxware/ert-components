This component is used to play audio or video from local media files or stream from remote URLs. If the media is an audio file then there is no widget displayed in the GUI, however a widget is still required in the GUI Builder, LGB. For video media the position and dimensions of the widget are specified in the widget properties in the GUI Builder, LGB. In addition the data inputs [In]off.x and [In]off.y can be used to change the position of the widget when the input event [In]setWindow is asserted, by specifying the offset from its original position in the x and y axis respectively. The data inputs [In]wid and [In]ht can be used to change the width and the height of the widget when the input event [In]setWindow is asserted. It should be noted that the data inputs [In]off.x and [In]off.y specify the offset in the x and y axis from its original position and the data outputs [Out]abs x and [Out]abs y refer to the absolute x and y coordinates of the widget in reference to the viewport. This allows the data output to be used to detect if widgets are overlapping in the GUI.

The input event [In]set input is used to load the media file as specified by the data input [In]path/URL and configure the decoder. The input events [In]play , [In]pause , [In]reverse , [In]faster , [In]slower and [In]stop control the playback of the media. The input events [In]faster and [In]slower increase and descrease the playback speed by the some increment that is implementation specific but typically doubles the playback speed each time it is triggered. So to return the playback speed to normal (100%) after doubling the speed 3 times by triggering [In]faster , [In]slower must be triggered 3 times.

During playback, when the input event [In]set pos is asserted, the value presented to the data input [In](%) specifies the point (as a percentage of the length of the media) at which the media should be played from. Similarly when the input event [In]set time is asserted, the value presented to the data input [In](s) specifies the time (in seconds) at which the media should be played from. Please note, these values are not persistent and the media will always play from the start when the input event [In]play is asserted.

The input events [In]to front and [In]to back are used to change the z-order of the widget and bring the media to the front and obscure other widgets or to send the media to the back and show other widgets on top of it. The input event [In]setVol takes the value presented at the data input [In](%) and sets the volume of the playback accordingly.

When the input event [In]getinfo is asserted, information is presented to the data outputs corresponding to the position (%) and time (s) inputs events [In]set pos and [In]set time . Information is also presented at the data outputs [Out]length info and [Out]speed info regarding the length of the media (in seconds) and the current playback speed (as a percentage of normal speed).
