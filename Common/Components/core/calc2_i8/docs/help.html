8 Input Integer Calculation  Misc ↓ Params ↓ Ports ↓

This component allows a mathematical expression to be entered in the Expression parameter, and performs an operation on the data inputs [In]A, [In]B, [In]C, [In]D, [In]E, [In]F, [In]G, [In]H and presents the result to the data output.

The integer operations that are supported are as follows: +, -, *, /, %, ^, abs(x), square(x), min(x,y), max(x,y), sin(α,Θ), cos(α,Θ) where α is a multiplier applied to the result and Θ is the angle. Any one of the data inputs A to H can be substituted for x,y,α or Θ, for example (A*B)/square(B).
