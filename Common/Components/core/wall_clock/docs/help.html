wall_clock Misc ↓ Params ↓ Ports ↓

This component is used to set and retrieve the current system date and time. The date-time format is the w3c standard where the complete date is displayed with the hours, minutes and seconds in the format YYYY-MM-DDThh:mm:ss where YYYY is a 4-digit year, MM is a 2-digit month, DD is a 2-digit day of the month, hh is 2 digits of the hour, mm is 2 digits of the minute and ss is 2 digits of the second. For example 1997-07-16T19:20:30 is a valid date-time string.

When the input event [In]get is asserted, the current date and time is presented to the data output [Out]Date String in the w3c format described above and the corresponding output event is triggered. Also the number of minutes elapsed since 1970-01-01T00:00:00 is presented to the data output [Out]Mins 1970 and the residual number of seconds presented to the data output [Out]& secs.

When the input event [In]set is asserted, the sytem date and time is set to the date-time string, in the w3c format described above, presented to the data input [Out]time.

format type

The output date string format.

0 for W3C datetime format.

1 for Human readable format (e.g. "2023 Jun 14 14:21:54 BST").

2 for Human readable format with weekdays (e.g. "Wed 2023 Jun 14 14:21:54 BST").

3 for YYYY-MM-DDThh:mm:ss format.
