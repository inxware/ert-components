Random Number Generator Misc ↓ Params ↓ Ports ↓

This function block outputs a random number within the range.

Every seed has its own specific random sequence of numbers. to get a truly random sequence consider making the seed something that changes (like the time).

For maximum security uses, use the full random value. For probability uses, divide the value by the maximum.
