Use this component to retrieve a list of applications available on a Devman Server and install them on your node. Note: This component is only functional if you have a Devman server subscription of your own Devman server instance.
Mode parameter detailed explanation:

0 install standard app

1 install as the home app

2 as temp app.

The app will only run once and may not be stored in the device. Once exited, the Info port retrieves various meta data strings for the given application.
