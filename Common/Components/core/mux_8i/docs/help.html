MultiplexEightInputInteger Misc ↓ Params ↓ Ports ↓

This component is used to take multiple input data (in this instance integer data), and present one as the output data depending on the events received. When an event is received, then the data at the corresponding input is presented to the output [Out]o. For example if an event is received at input [In]2, the data at input [In]i2 is presented at output [Out]o.
