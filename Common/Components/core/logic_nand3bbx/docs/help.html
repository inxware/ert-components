LogicThreeInputNand Misc ↓ Params ↓ Ports ↓

This component performs a logical NAND operation on the Boolean data presented to the input ports and presents the result of the logical operation to the output data port.

A logical NAND operates as a negated AND and will present a value of "FALSE" to the data output if and only if, all of the data inputs are "TRUE". In all other cases the data output will be "TRUE".

The logical operation is performed when the input event is triggered and the result of the Boolean operation is presented to the Boolean data output. The output event is triggered to signal the completion of the logical operation.
