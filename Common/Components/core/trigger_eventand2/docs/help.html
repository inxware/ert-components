This component is used to AND together the input events and operates as a Latching AND with an external reset. The output event is triggered only after all the input events have fired. Once the output event is triggered and until the reset input event is asserted (the input event at the bottom of the component), the output event will be triggered every time an input event is asserted. When the reset input event is triggered, all the input events must fire again for the output event to be triggered.
