ComparatorGreaterInt1 Misc ↓ Params ↓ Ports ↓

This component is used to compare two integer values and trigger different output events dependent on whether one value is greater than the other.

If the data input [In]B is greater than [In]A then the boolean data output is set to "TRUE" and the output event [Out]t is triggered. Else the boolean data output is set to "FALSE" and the output event [Out]f is triggered.

If there is no input connected to [In]B value specified by the parameter Constant is compared to the the data input [In]A.
