string_format_8 Misc ↓ Params ↓ Ports ↓

This component formats 8 string inputs when triggered by the input event. The formatting is performed as specified by the Format parameter, which uses C-style formatting conventions. If only one of the two input strings is connected, then the formatting will be performed on that string only. If both input strings are connected then the two string will be formatted.

The standard c escape character processing is applied to the characters in the constant format string entered:\n,\t,\r,\f
