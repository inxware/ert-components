string_scanf

This component parses a string to extract substring as specified by scanf format specificifiers.

This only supports the %s specifier for extracting substrings. *% number formats can be used to skip numbers in a string. Numbers can be read extracted in their oriinal string formats using [0,1,2,3,4,5,6,7,9] or [^D], where D is some form of delimeter.
