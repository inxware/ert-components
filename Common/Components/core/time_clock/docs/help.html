time_clock Misc ↓ Params ↓ Ports ↓

This component is used to create periodic timed events with a period specified by the parameter Time Interval or by overriding the parameter by presenting a value to the data input [In]period. Each periodic event triggers the output event [Out]clk. The clock starts when the input event [In]start is asserted and stops when the input event [In]stop is asserted.

The clock can be configured to only fire once or to fire repeatedly by setting the parameter Periodic Flag or by overriding the parameter by presenting a value to the data input [In]rpt. Similarly the clock can be configured to reset the time until the next clock event is triggered, every time the input event [In]start is asserted, by setting the parameter Retriggerable Flag or by overriding the parameter by presenting a value to the data input [In]retrig.
