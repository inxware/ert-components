text Case Switch

This component is used to fire an event corresponding case text value is matched to the test input

Ports

  • [In] Go:

    Event input, triggers the output event corresponding to the test value to the case values.

  • [In] test:

    test value to compare to the case values below

  • [In] case 1:

    case value to fire event port 1.

  • [In] case 2:

    case value to fire event port 2.

  • [In] case 3:

    case value to fire event port 3.

  • [In] case 4:

    case value to fire event port 4.

  • [In] case 5:

    case value to fire event port 5.

  • [In] case 6:

    case value to fire event port 6.

  • [In] case 7:

    case value to fire event port 7.

  • [In] case 8:

    case value to fire event port 8.

  • Event output 1.

  • [Out] 2:

    Event output 2.

  • [Out] 3:

    Event output 3.

  • [Out] 4:

    Event output 4.

  • [Out] 5:

    Event output 5.

  • [Out] 6:

    Event output 6.

  • [Out] 7:

    Event output 7.

  • [Out] 8:

    Event output 8.

  • [Out] Default:

    Asserted if no cases are found (or no test line is ocnnected)

Parameters

8 default static case texts can be included here.

NOTE: If spaces are used in the cases then the string must be contained in double quotes!!!
