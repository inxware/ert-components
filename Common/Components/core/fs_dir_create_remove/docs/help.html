This component is used to create and remove directories on the host device. A directory is created with the path specified by the parameter Directory when the input event [In]create is asserted. The path specified by the parameter Directory is overridden by the data input [In]path. If the directory was successfully created then the input event [Out]created is triggered else [Out]error is triggered.

A directory is removed at the path specified the by parameter Directory when the input event [In]remove is asserted. The path specified by the parameter Directory is overridden by the data input [In]path. If the directory was successfully removed then the input event [Out]removed is triggered else [Out]error is triggered. An error is produced if there is no directory at the path specified or if the directory could not be removed. The EmptyOnly parameter is a Boolean value that specifies if the directory must be empty before it can be successfully removed.
