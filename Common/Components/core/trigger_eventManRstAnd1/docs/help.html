EventManResetOneInputAnd

This component is a single input AND with a manual reset. It is asserted once and will not fire again until manually reset. As it is a single input AND, it operates as an event gate that will assert when an event is presented but then block further events from being asserted until it is reset again.

Ports

  • [In] :

    Input event, event to be AND'd together.

  • [Out] :

    Output event, fires when the input event is asserted iff the component is reset.

  • [In] -Reset:

    Input event, resets the AND.

  • [Out] :

    Output event, fires when the component has been reset.

Parameters

None.

State Machine

Stateless.
