This component is used to identify which event has fired. The use case is where there is a set of components that can be triggered by many events but the identity of the event needs to be known after the set of components has completed it process.

When one of the input events 1-8, is triggered, the output event [Out]Go is asserted and the index of the event that was triggered is presented to the data output [Out]Ind. The value of the the data output [Out]Ind can then be used to identify which event was triggered.

The Event Identifier has two modes of operation, controlled by the parameter Requires Resetting. Mode 1 is the default, when the parameter Requires Resetting is set to 1, then once the output event [Out]Go has been triggered, it cannot be triggered again until the Event Identifier is reset by triggering the input event [In]Reset. Mode 2, when the parameter Requires Resetting is set to 0, will automatically reset the Event Identifier everytime it is triggered so that everytime one of the input events 1-8, is triggered, the output event [Out]Go is asserted and the index of the event that was triggered is presented to the data output [Out]Ind.
