AprilTag detects various AprilTag families from a picture with available optimisation parameters. This can only take the grayscale input so the Frame Format function block must be used before this.

Name Type Default Min Max Description
apriltag_family I 0 0 7 The AprilTag family to be detected. The enumeration is:
Enumeration ID
tag36h11 0
tag25h9 1
tag16h5 2
tagCircle21h7 3
tagCircle49h12 4
tagStandard41h12 5
tagStandard52h13 6
tagCustom48h12 7
quad_decimate F 2 1 25 Detection of quads can be done on a lower-resolution image, improving speed at the cost of pose accuracy and a slight decrease in detection rate. Decoding the binary payload is still done at full resolution.
quad_sigma F 0 0 1 What Gaussian blur should be applied to the segmented image (used for quad detection?) Parameter is the standard deviation in pixels. Very noisy images benefit from non-zero values (e.g. 0.8).
refine_edges B 1 0 1 When true, the edges of each quad are adjusted to "snap to" strong gradients nearby. This is useful when decimation is employed, as it can increase the quality of the initial quad estimate substantially. Generally recommended to be on (true).
decode_sharpening F 0.25 0 1 How much sharpening should be done to decoded images? This can help decode small tags but may or may not help in odd lighting conditions or low light conditions.
Ports Top ↑ Misc ↓ Params ↑
In Ev.
config Configure the detector. The detector has been initialised and configured by the function block parameters but can be re-configured during operation.
detect Detect the AprilTag from the frame.
Data In
family This follows the same definition of apriltag_family parameter. Out of range value will be default to 0 (i.e. tag36h11). If not connected, the parameter value is used.
decimate This follows the same definition of quad_decimate parameter. Only the value that is greater than 0 is accepted, or it will be ignored. If not connected, the parameter value is used.
sigma This follows the same definition of quad_sigma parameter. Only the value that is greater than or equal to 0 is accepted, or it will be ignored. If not connected, the parameter value is used.
refine_edges This follows the same definition of refine_edges parameter. If not connected, the parameter value is used.
sharpen This follows the same definition of decode_sharpening parameter. Only the value that is greater than or equal to 0 is accepted, or it will be ignored. If not connected, the parameter value is used.
stream_id The ID of the input stream for detection. The frame must be grayscale. This is a mandatory input.
Out Ev.
-- (after config) Configuration is finished.
-- (after detect) The detection is successful without any error. Note that this would still trigger when no AprilTag is detected but the detection process has no error!
err The detection process encounters an error.
Data Out
errno Error number of detection process. The enumeration is:
Enumeration Errno Description
OK 0 No error.
NO_STREAM_ID 1 Stream ID is not given.
INVALID_STREAM 2 Stream data/format is invalid.
INSUFFICIENT_RESOURCE 3 Insufficient memory for detection process.
NO_OUTPUT 4 JSON output port is not connected.
INVALID_INPUT 5 Stream ID input is invalid.
JSON The result of the detection in JSON. The format is: (Note that <i> means the placeholder of i. For example, id<i> will be id0 if i is 0.)
Key Type Description
n Integer Total Number of AprilTags detected. If 0, then there are no other keys in this JSON string.
id<i> Integer The AprilTag ID of the i-th detection. The i starts from 00.
xlt<i> Float X Coordinate of left-top corner of the i-th detected AprilTag. The i starts from 00.
ylt<i> Float Y Coordinate of left-top corner of the i-th detected AprilTag. The i starts from 00.
xrt<i> Float X Coordinate of right-top corner of the i-th detected AprilTag. The i starts from 00.
yrt<i> Float Y Coordinate of right-top corner of the i-th detected AprilTag. The i starts from 00.
xrb<i> Float X Coordinate of right-bottom corner of the i-th detected AprilTag. The i starts from 00.
yrb<i> Float Y Coordinate of right-bottom corner of the i-th detected AprilTag. The i starts from 00.
xlb<i> Float X Coordinate of left-bottom corner of the i-th detected AprilTag. The i starts from 00.
ylb<i> Float Y Coordinate of left-bottom corner of the i-th detected AprilTag. The i starts from 00.
This port must be connected, or it would generate NO_OUTPUT error (see err and errno).
