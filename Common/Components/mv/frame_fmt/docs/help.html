Frame Fmt Misc ↓ Errors ↓ Params ↓ Ports ↓

Frame Fmt converts a camera frame from its current pixel format to a different one (e.g. colour to greyscale, or 8-bit to normalised float for ML input) and writes the result into a new frame buffer. The converted frame can then be passed to downstream blocks such as Frame Crop, Frame Resize, Frame Show, or ML inference blocks, exactly like any other frame.

The target format is given by format, which can be set as a static parameter and/or overridden at runtime via the data_format input port.

If the target format resolves to 0 (the default BGR format) the block fires err with errno 2 (UNUSED) and does not produce a converted frame — there is nothing to convert to. This lets you conditionally bypass formatting without disconnecting the block.

Note: this is a slow, CPU-only conversion — it does not use the GPU. Avoid running it every frame on a high-resolution stream if it can instead be placed after a Frame Crop / Frame Resize that has already reduced the frame to the size actually needed downstream (e.g. an ML model's input tensor size).

Error Codes Top ↑ Misc ↓ Ports ↑ Params ↑

The errno output port carries one of the following values after each invocation of format.

Value Name Meaning Common causes & remedies
0 OK Format conversion succeeded. — -- event fires.
1 FAILED Format conversion failed.
  • No valid source frame: the stream_id input is not connected or the upstream block has not yet produced a frame.
  • This block's internal frame buffer is not initialised (frame slot allocation failed at startup).
  • The requested format value is not one of the implemented values (0–3) — see the format table under Parameters.
  • The HAL format-conversion function returned an error (e.g. memory allocation failure).
2 UNUSED Target format resolves to 0 (default) — conversion was skipped. Set format to a non-zero, implemented value (1–3), either as a parameter or via a connected data_format input port. If zero-bypass is intentional, ignore this event or connect it to a pass-through path.
