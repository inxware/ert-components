Modbus Config is used to configure the MODBUS-RT interface.

name type default min. max. description
bus_id I 0 0 100 Bus ID for the MODBUS communication.
master B 0 0 1 Whether MODBUS is in Master mode.
data_mode I 0 0 2 Whether MODBUS is in RTU, ASCII or TCP/IP mode. 0 if RTU, 1 if ASCII, 2 if TCP/IP.
port_id I 0 0 2147483647 The port ID of the MODBUS interface.
ip S 127.0.0.1 The target IP if in TCP/IP mode.
cert S The certificate filename of the MODBUS TCP/IP communication.
