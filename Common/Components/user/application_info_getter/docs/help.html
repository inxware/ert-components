application_info_getter Misc ↓ Params ↓ Ports ↓

This component retrieves information about locally installed applications, including their names, descriptions, and icons.

Parameters Top ↑ Misc ↓ Ports ↓
Ports Top ↑ Misc ↓ Params ↑
In Ev.Description
get listStarts retrieving the list of locally installed applications.
app infoRequests detailed information about a specific application.
get defaultFetches the default application details.
set defaultSets a specific application as the default.
uninstallUninstalls the specified application from the device.
Data InDescription
keywordsKeywords to filter applications in the list.
app name[info]Application name to retrieve information for.
app name[setDefault]Application name to be set as the default.
app name[delete]Application name to be uninstalled.
Data OutDescription
listReturns the list of locally installed applications.
amountReturns the total number of applications matching the criteria.
infoReturns detailed information about a specific application.
nameReturns the name of the application.
commercial NameReturns the commercial name of the application.
versionReturns the version of the application.
descriptionReturns the description of the application.
app name[getDefault]Returns the name of the default application.
errorsReturns errors encountered during operations.
Out Ev.Description
-----[list]Indicates the completion of retrieving the application list.
error[list]Indicates an error occurred while retrieving the application list.
-----[info]Indicates the completion of retrieving application information.
error[info]Indicates an error occurred while retrieving application information.
-----[getDefault]Indicates the completion of getting the default application.
error[getDefault]Indicates an error occurred while getting the default application.
-----[setDefault]Indicates the completion of setting an application as default.
error[setDefault]Indicates an error occurred while setting an application as default.
-----[delete]Indicates the completion of uninstalling an application.
error[delete]Indicates an error occurred while uninstalling an application.
