This function block provides a TCP IP ot UDP IP socket that listens for incoming connections and data.

State behaviour: The component is stateful and must be in the open state to send or receive data (TCP or UDP). Only one client at a time may connect with the socket until it is disconnected by the client or the server is closed and re-opened.

On receiving data the client IP address is assrted on an output port. Further data may be sent by the client in following packets. There is no marshalling of data by the function block and overruns are possible with large data packets!
