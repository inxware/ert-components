Socket Server

This function block provides a TCP IP ot UDP IP socket that listens for incoming connections and data.

State behaviour: The component is stateful and must be in the open state to send or receive data (TCP or UDP). Only one client at a time may connect with the socket until it is disconnected by the client or the server is closed and re-opened.

On receiving data the client IP address is assrted on an output port. Further data may be sent by the client in following packets. There is no marshalling of data by the function block and overruns are possible with large data packets!

Ports

  • [In] Open:

    Opens the port provided and listens for connections

  • [In] url

    The local IP inteface on which to listen for connections (typically localhost/127.0.0.01).

  • [In] port

    The local IP port on which to listen for connections.

  • [In] close:

    Closes the port provided and stops listening for TCP and UDP connections and data packets

  • [Out]Received:

    Asserted when data is received from a client. Only active when the port is opnened (even in UDP mode).

  • [Out] data

    Data received. NUll terminated string. -> Note this is not buffered so must be consumed immediately (e.g. into a FIFO) to ensure large data streams are acquired

  • [Out] size:

    Number of bytes received.

  • [Out] source:

    IP Address of remote client that has sent data.

  • [In] send

    Send data to connected client.

  • [In] data

    Data to send to client. Binary or string data may be sent, but null terminated string format is expected of there is no dta length specified.

  • [In] inSize:

    Size of data buffer to send back to the client.

Parameters

  • Interface : The local network interface to listen on (usually localhost : 127.0.0.1)
  • Port : The IP port to listen for client connections.
  • udp : set to 1 for UDP data grams and 0 for TCP data streams.

State Machine

Statefull.
