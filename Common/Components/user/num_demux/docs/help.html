Numeric Digit Demultiplexer Misc ↓ Params ↓ Ports ↓

Demultiplex a floating point number into digits. It supports up to 6 whole number digits and 2 decimal places. For example, i1=123456.12, the outputs are -ve=False, n1=1, n2=2, n3=3, n4=4, n5=5, n6=6, d1=1, d2=2.
