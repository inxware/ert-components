Digit Display Misc ↓ Params ↓ Ports ↓

The Digit Display function block receives numerical data and displays it on a seven-segment display. This block is intended for use with compatible hardware that supports numerical display functionality. It provides a simple interface for setting the display, specifying the number to display, the display ID, and the digit position.
