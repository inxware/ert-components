Pulse Width Modulation Misc ↓ Ports ↓

This function block allows hardware-enabled PWM (Pulse Width Modulation) to be configured to represent percentage values converted into mark-to-space ratio square waves at a fixed frequency. It is used to control devices like motors, LEDs, and other hardware components that require a variable signal to adjust their operation.

The pin ID (as for GPIO) is used to determine which pins are being configured and used as PWM. This is typically a hardware-specific option, and Pin IDs should be determined for the target hardware.

Ports Top ↑ Misc ↓
Data In Description
config Event to configure PWM settings.
enable Event to enable or disable PWM output.
set duty Event to set the duty cycle of the PWM signal.
hz Input port to specify frequency in Hz.
% Input port to specify duty cycle as a percentage.
pin Input port to specify which pin is being used for PWM output.
