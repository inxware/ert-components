RealTimeClock Misc ↓ Params ↓ Ports ↓

The RealTimeClock function block outputs the current real-time in various formats based on the connected data outputs. It provides input and output ports for time setting and retrieval, allowing integration with systems that require accurate timekeeping functionality. This function block is useful in applications such as scheduling, logging, time synchronization, or any task relying on the precise time of day.
