This function will retrieve data from the schedule information stored on a device. There are multiple formats supported for the schedule data to allow for different levels of compaction. These include:

  • Boolean 30 minute resolution
  • 0-255 (8bit) value at 30 minute resolution
  • 0-255 (8bit) value at 1 minute resolution
  • 0-255 (8bit) value at 1 second resolution
  • -32767 - 32768 (16bit) value at 1 second resolution
The format of the binary format is provided by inx.

See Also: for media scheduling applications a SMIL.xml-based scheduler is available with more complex repetition cases and metadata handling.
