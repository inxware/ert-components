MQTT Client Misc ↓ Params ↓ Ports ↓

MQTT Client connects to a MQTT Server. It supports the TLS protocol, which could be toggled on or off. The client needs to pass in the username and password in order to login.

Once the connect event is triggered, it will attempt to connect using the provided details. If connected successfully, it will trigger the connect output event [Out]--. Otherwise it will trigger the Disconnected [Out]-- event.
