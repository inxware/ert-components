Runtime Control Misc ↓ Params ↓ Ports ↓

The Runtime Control function block provides system-level operations to control the current Embedded Human System (EHS) window. This includes the ability to exit the EHS, bring the EHS window to the foreground, or send it to the background. The component is designed to manage the visibility and operational state of the EHS in embedded systems.
