Socket Client

This function block provides a TCP IP ot UDP IP socket for connecting to IP ports on remote or local servers.

State behaviour: The component is stateful and must be in the open state to send or receive data (TCP or UDP) to and from a server.

Once a connection to a server is established data may be received from the server. Further data may be sent by the server in following packets. There is no marshalling of data by the function block and overruns are possible with large data packets!

Ports

  • [In] Open:

    Opens the port provided and try connect to the server

  • [In] url

    The remoe IP address to connect to.

  • [In] port

    The remote IP port (service) on which to connect to.

  • [In] close:

    Disconects from the server and stops accepting data packets from the client

  • [Out]Received:

    Asserted when a data respose is received from a server. Only active when the port is opnened (even in UDP mode).

  • [Out] data

    Data received. NULL terminated string. -> Note this is not buffered so must be consumed immediately (e.g. into a FIFO) to ensure large data streams are acquired

  • [Out] size:

    Number of bytes received.

  • [In] send

    Send data to connected server.

  • [In] data

    Data to send to server. Binary or string data may be sent, but null terminated string format is expected of there is no dta length specified.

  • [In] inSize:

    Size of data buffer to send back to the server.

Parameters

  • Interface : The remote network interface to connect to
  • Port : The IP port to connect to.
  • udp : set to 1 for UDP data grams and 0 for TCP data streams.

State Machine

Statefull.
