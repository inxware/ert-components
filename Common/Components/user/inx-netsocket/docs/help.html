This function block provides TCP/IP or UDP/IP socket communication for connecting to IP ports on remote or local servers. The component allows for sending and receiving data over a network using either the TCP or UDP protocol. The component is stateful and must be in the open state to send or receive data.

Once a connection to a server is established, data can be sent to and received from the server. There is no data buffering by the function block, so large incoming data packets may result in overruns if not consumed immediately.
