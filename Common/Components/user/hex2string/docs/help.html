Hex String to Raw Misc ↓ Params ↓ Ports ↓

The `Hex String to String` function block is designed to convert a hexadecimal string into its corresponding binary byte array. This is particularly useful when processing data in hexadecimal format and converting it to raw binary data for further use in applications. If the input hex string has an odd number of characters, the function will prepend a '0' in cases where reading as text string is required.
