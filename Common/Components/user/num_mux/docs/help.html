Numeric Digit Multiplexer Misc ↓ Params ↓ Ports ↓

Multiplex up to 6 whole number digits and 2 decimal places into a floating point number. For example, -ve=True, n1=1, n2=2, n3=3, n4=4, n5=5, n6=6, d1=1, d2=2, the output is -123456.12.
