JSON Data Block

This component provides stores a JSON file and the allows values to be queried using JSONPath query language.

Data parser

Ports

  • reset
    - remove the JSON file accumulated through read.
  • read
    - Loads and concatenates a JSON data structure string in memory to be queried.

    The query string is a subset of JSON path not supporting wild cards. An extension to this is the use of '?' as a query string for a field, which will return a list of map keys rather than values at the given nesting level in the JSON data (See examples below).

  • query
    Query the JSON using JSONPath and Key listing query strings of the form

    query JSON values and subtrees
    [firstLevel][secondLevel][X], where each field represents the nesting key path to a value (or JSON subtree) under the final map key 'X'.

    query strings may also be of the form

    ["firstLevel"][ "secondLevel"][...]

    ['firstLevel']['secondLevel'][...] or

    firstLevel.secondLevel or

    firstLevel

    $.firstLevel

    query key names using wild cards
    The only wildcard support provided is for retrieving a list of map keys (rather than values) at a node in the JSON.

    the ? operator is used. e.g. [?] - returns all the first level map keys. Array are ignored

    [X][?] - returns all the maps keys under the the 'X' map. Arrays are ignored
