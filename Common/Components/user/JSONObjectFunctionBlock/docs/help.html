JSON Object Misc ↓ Query ↓ Ports ↓

JSON Object holds an in-memory JSON document and allows up to 8 simultaneous path queries against it. Connect a JSON string to the data port and fire read to load it, then fire query to extract values via the path1–path8 inputs. Results are emitted on result1–result8 as strings.

Ports Top ↑ Misc ↓ Query ↓
In Ev.
reset Clear the in-memory JSON document.
read Parse the string on the data port into the in-memory document. Fires --[read] on completion.
query Evaluate all connected path inputs against the document. Results appear on the corresponding result outputs. Fires --[query] on success or error on failure.
Data In
data JSON string to be loaded when read fires.
path1 – path8 Query path strings, evaluated when query fires. Each path selects one value from the document; the result is written to the matching result port (path1 → result1, …, path8 → result8). See the Query Syntax section below.
Out Ev.
--[reset] Fired when reset completes.
--[read] Fired when the JSON document has been successfully parsed.
--[query] Fired when all queries completed without error.
error Fired when a query fails (e.g. path not found or document not loaded).
Data Out
result1 – result8 Query result strings. Each output corresponds to the path port with the same index. The value is the JSON scalar at the queried path (number, string, boolean, or null) converted to a string. If the path is not connected or not found, the output is empty.
Query Syntax Top ↑ Misc ↓ Ports ↑

A query path is a dot-separated sequence of keys and array indices that navigates the JSON tree to a single scalar value.

Path element Meaning Example
key Select the named field from a JSON object. det_cnt
N (integer) Select the N-th element (0-based) from a JSON array. res.0 → first element of the res array
key.subkey Nested object navigation. res.0.cls

Examples using the object-based JSON output from the Image Inference block:

{"type":1,"det_cnt":2,"res":[
  {"cls":0,"lbl":"person","cnf":0.9200,"x":320.0,"y":240.0,"w":100.0,"h":80.0},
  {"cls":2,"lbl":"car",   "cnf":0.8800,"x":500.0,"y":300.0,"w":200.0,"h":120.0}
]}

det_cnt2

If the path does not exist in the current document, the corresponding result port is empty and the error event fires. Only scalar values (numbers, strings, booleans, null) can be retrieved; querying a path that resolves to an object or array also triggers error.
