JSON Stream Parser Function Block Misc ↓ Params ↓ Ports ↓

The `JSON Stream Parser` function block processes a text stream and generates events related to JSON parsing. This function block is essential for systems that need to handle JSON data in real-time, parsing the content and triggering appropriate events based on the data received.
