    <div>
        <h2>Functionality:</h2>
        <p>The Map Int function block is designed to map input integer values to output integer values based on a predefined map. Here's how it works:</p>
        <ol>
            <li>The function block accepts up to 8 input integers (i1 to i8).</li>
            <li>Each input integer is processed through the mapping function.</li>
            <li>If an input value is found in the map, it is replaced with its corresponding mapped value.</li>
            <li>If an input value is not found in the map, it is replaced with the "not found" default value.</li>
            <li>The mapped values are output through the corresponding output ports (o1 to o8).</li>
            <li>The mapping process is triggered by the input event 'i' and completes with the output event 'o'.</li>
        </ol>
        <p>The map is defined as a string parameter in the format "key1=value1,key2=value2,...". The function block supports up to 30 key-value pairs in the map.</p>
