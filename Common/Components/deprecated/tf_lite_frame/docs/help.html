TensorFlow Lite from Frame passes an image frame to a TensorFlow Lite machine learning model and returns inference results as JSON. Supports object detection models including YOLOv5 and similar architectures. The model is loaded once via the load event and then invoked repeatedly via the do event, each time consuming the frame identified by stream_id.

Name Type Default Min Max Description
Model Type I 0 0 10 The type of model loaded. Determines the inference output format and post-processing applied to raw model output.
Conf Thres F 0.5 0.0 1.0 Confidence threshold for filtering inference results. Detections below this score are discarded. Range 0.0 to 1.0.
Thread Count I 2 0 20 Number of threads used for model inference. Set to 0 to use the platform default. Ignored on platforms that do not support multi-threaded inference.
Flat JSON B 0 0 1 When true, the json output uses a flat JSON structure instead of nested objects. Useful for simpler downstream parsing.
Use Application Dir B 0 0 1 When true, the model file path provided to model is resolved relative to the application directory. When false, it is resolved relative to the user data directory.
Ports Top ↑ Misc ↓ Params ↑
In Ev.
load Trigger model loading. Provide the model file path via model before firing this event.
do Run inference on the current frame. The frame is identified by stream_id. Fires -- on success.
Data In
model Path to the TensorFlow Lite model file (.tflite). Consumed by the load event.
stream_id Integer identifier of the camera or image stream frame to run inference on. Consumed by the do event.
Out Ev.
-- Fired when the model loads successfully.
err Fired when the model fails to load. Check errno for the error code.
-- Fired when inference completes successfully. Results are available on json.
Data Out
errno Error code from the most recent load attempt. Valid after the err event fires.
json Inference result in JSON format. Available after the -- event fires. Format depends on Model Type and the Flat JSON parameter.
