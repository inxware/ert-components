XinputInteger Misc ↓ Params ↓ Ports ↓

This component provides a way to expose an integer input, so that components in the parent workspace can pass data to the encapsulated subsytem. The data input is represented as a port on the ensulating function block, which can be viewed by pressing the 'up' button to display the parent workspace.
