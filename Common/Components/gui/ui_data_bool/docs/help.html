Two-way binding between the application and a single boolean property on a named object in the user interface. Trigger set to push a value into the property; changed fires when the property is altered from the UI side, delivering the new value on value_out.

The target is named by the two parameters: Object selects the UI object and Property selects the property on it. The default Object _qml_root_object_ is a sentinel meaning “the first root object of the UI”, so a single-window UI needs no naming at all. For anything else, set Object to the name the object is declared with in the UI definition (objectName in QML).

Property names are used exactly as written. Change notifications bind to <Property>Changed, the Qt/QML convention — a property declared in QML gets that signal automatically, and a C++-backed property needs a NOTIFY signal of the same name. Snake-case names are not camel-cased, so my_flag binds my_flagChanged.

Binding is deferred and there is no initial read. The UI often loads after the application starts, so the object lookup is retried in the background until the object appears. Nothing is emitted at bind time: changed fires only on the first real property change. If the application needs a known starting state, drive set once during start-up.

Watch for feedback loops. A set that actually alters the value normally makes the UI emit the property's change signal, so changed fires shortly afterwards on this same block. Take care when wiring changed back to set, directly or through other blocks.

The block is only built for targets whose HAL implements the UI binding layer (currently the Qt/QML targets).

done Fires once the value has been handed to the UI layer. It does not indicate that the UI has repainted, nor that the named object exists yet — a write issued before the UI has loaded is applied when the object appears.
changed Fires when the bound property changes in the UI, for example through user interaction. Asynchronous: it is not a response to any input event on this block. The new value is on value_out.
