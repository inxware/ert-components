This component is used to specify the position (relative to the screen origin), dimensions, colour and transparency of the viewport. These properties are specified in the viewport widget properties in the GUI Builder, LGB. In addition the data inputs [In]off.x and [In]off.y can be used to change the position of the viewport by specifying the offset from its original position in the x and y axis respectively. The data inputs [In]off.wid and [In]off.ht can be used to specify an offset in the width and the height of the viewport from the original dimensions and [In]alpha can be used to change the alpha value of the transparency of the viewport.

The input event [In]create will create a surface on which widgets can be displayed and [In]destroy destroys the surface. When the input event [In]create is triggered, data is presented to outputs [Out]abs x , [Out]abs y , [Out]wid and [Out]ht , describing the absolute position and dimensions of the viewport as created.

The input events [In]show and [In]hide will show and hide the viewport. The state of the viewport as shown or hidden is persistent, so that if [In]show is asserted before [In]create , the viewport will be shown when [In]create is asserted.

When the input event [In]update is asserted, the values presented to the inputs [In]off.x , [In]off.y , [In]off.wid , [In]off.ht and [In]alpha will be used to update the viewport widget properties. Data is presented to outputs [Out]abs x , [Out]abs y , [Out]wid and [Out]ht , describing the updated absolute position and dimensions of the viewport. It should be noted that the data inputs [In]off.x and [In]off.y specify the offset in the x and y axis from its original position and the data outputs [Out]abs x and [Out]abs y refer to the absolute x and y coordinates of the viewport in reference to the screen origin.

In Ev.
create

Input event, creates a surface to display widgets.

destroy

Input event, destroys the surface displaying widgets.

show

Input event, shows the viewport.

hide

Input event, hides the viewport.

update

Input event, updates the properties of the viewport.

Data In
off.x

Data input, specifies the offset in the x axis of the viewport from its initial position when the update event is asserted.

off.y

Data input, specifies the offset in the y axis of the viewport from its initial position when the update event is asserted.

off.wid

Data input, specifies the offset in width of the viewport from its original dimensions when the update event is asserted.

off.ht

Data input, specifies the offset in height of the viewport from its original dimensions when the update event is asserted.

alpha

Data input, specifies the alpha transparency of the viewport when the update event is asserted.

Data Out
abs x

Data output, the x coordinate of the viewport relative to the screen origin presented when the create or update events are triggered.

abs y

Data output, the y coordinate of the viewport relative to the screen origin presented when the create or update events are triggered.

wid

Data output, the width of the viewport presented when the create or update events are triggered.

ht

Data output, the height of the viewport presented when the create or update events are triggered.

abs x

Data output, the x coordinate of the mouse pointer relative to the viewport origin presented when the mouse down or mouse up events are triggered.

abs y

Data output, the y coordinate of the mouse pointer relative to the viewport origin presented when the mouse down or mouse up events are triggered.

off.x

Data output, the offset in the x coordinate from the mouse down coordinates and the current mouse pointer coordinates presented when the mouse drag event is triggered.

off.y

Data output, the offset in the y coordinate from the mouse down coordinates and the current mouse pointer coordinates presented when the mouse drag event is triggered.

Out Ev.

Output event, triggered when the input event [In]create is asserted.

Output event, triggered when the input event [In]destroy is asserted.

Output event, triggered when the input event [In]show is asserted.

Output event, triggered when the input event [In]hide is asserted.

Output event, triggered when the input event [In]update is asserted.

mouse down

Output event, triggered when the user presses the mouse button.

mouse up

Output event, triggered when the user releases the mouse button.

mouse drag

Output event, triggered when the user moves the mouse with the button held down which is interpreted as a drag event.
