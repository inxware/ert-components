RS-485 Config Misc ↓ Params ↓ Ports ↓

RS-485 Config sets advanced RS-485/RS-422 line parameters for Sfera Labs boards via sysfs. It complements the generic uart_config block with options only available through the Sfera Labs kernel driver.

echo enables local echo mode: the transmitter's own data is looped back on the receive path. Disable for normal half-duplex RS-485; enable for RS-422 full-duplex diagnostics.

termination enables the 120 Ω line termination resistor on boards that support it (Iono Pi Max, Strato Pi Max expansion boards). Enable on the two physical endpoints of the RS-485 bus only.

Call this block after the uart block's start event has fired. Use the same Port parameter index as the corresponding uart block.
