SD Card Select Misc ↓ Params ↓ Ports ↓

SD Card Select controls the dual-SD card hardware multiplexer on Strato Pi Max boards.

The Strato Pi Max has two physical SD card slots connected to the Raspberry Pi CM via a hardware switch. select switches the active slot (0 or 1) immediately; a system reboot is required for the OS to boot from the newly selected card. read_active reads back the currently selected slot without changing it.

Typical use: at startup, read the active slot to verify which card is in use. After an OTA firmware update to the standby card, fire select to switch, then reboot.
