USB Power Misc ↓ Params ↓ Ports ↓

USB Power controls power to individual USB ports. Provides software-controlled power switching on its USB host ports, allowing connected devices to be power-cycled without rebooting the system. This is useful for resetting unresponsive USB peripherals (modems, USB hubs, industrial dongles).

This is not supported on all hardware , boards or OSs!

The Port parameter selects which USB port this instance controls (1–4). Use multiple instances of this block to control different ports independently.
