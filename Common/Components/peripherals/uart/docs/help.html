Name Type Default Description
GPIO Switch I 0 Configures the GPIO switch for UART communication.
RS485 B 0 Enables or disables RS485 mode for UART communication.
ComPort I 0 Default UART port to open. On Windows, specifies the physical COM port number (e.g. 3 = COM3, 5 = COM5). On Linux, specifies the device index (e.g. 1 = /dev/ttyUSB1). Set to 0 to use the platform default (UART 0). When the port input is connected its value takes precedence over this parameter.
