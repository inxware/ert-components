Detects when a key is pressed and asserts the character represented by the key and the ASCII or extended key code of the key.

When a non-control key is pressed the [Out]key event fires and asserts the ASCII or extended key code to the [Out]ascii port and asserts the character represented by the key to the [Out]char port.

The ASCII key codes asserted range from 32 (space) to 126 (~) inclusive. Please refer to http://www.asciitable.com/ for the full table of codes.

Control keys are also detected by this Function Block and integer codes are asserted on [Out]control [Out]id ports.
