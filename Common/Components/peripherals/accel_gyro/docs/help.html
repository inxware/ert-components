Accelerometer and Gyroscope Misc ↓ Params ↓ Ports ↓

AccGyro provides access to a combined IMU (Inertial Measurement Unit) with separate accelerometer and gyroscope channels. Both channels share a single enable/disable pair.

read_accel and read_gyro trigger independent reads; either may be used without the other. On platforms that provide only an accelerometer (e.g. Sfera Labs Exo Sense Pi), read_gyro never fires its gyro_done event.

Ports Top ↑ Misc ↓ Params ↑
In Ev.
enableEnable the IMU hardware. Must be called before any read_accel or read_gyro calls. Sets error_id and fires enabled on success.
disableDisable the IMU hardware. Sets error_id to 0 and fires disabled.
read_accelRead one accelerometer sample. Fires accel_done with Ax, Ay, Az on success. Does nothing if data is not available.
read_gyroRead one gyroscope sample. Fires gyro_done with Gx, Gy, Gz on success. Never fires on platforms without a gyroscope.
Data In
Out Ev.
enabledFired when the IMU has been successfully enabled.
disabledFired when the IMU has been disabled.
accel_doneFired when an accelerometer sample has been read successfully.
gyro_doneFired when a gyroscope sample has been read successfully.
Data Out
error_idError code from enable or disable. See error codes table below.
AxX-axis acceleration (g or mg — unit is platform-defined). Updated by read_accel.
AyY-axis acceleration. Updated by read_accel.
AzZ-axis acceleration. Updated by read_accel.
GxX-axis angular rate (deg/s). Updated by read_gyro.
GyY-axis angular rate (deg/s). Updated by read_gyro.
GzZ-axis angular rate (deg/s). Updated by read_gyro.
