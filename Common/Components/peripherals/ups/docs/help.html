UPS provides access to the uninterruptible power supply management on Strato Pi and Strato Pi Max boards.

read polls the current battery and mains status. For event-driven power management, the power_fail and power_restored output events fire automatically when the board kernel driver detects a mains transition — no polling is required for these.

battery_mv is reported in millivolts. Typical LiFePO4 range is 3000–3600 mV per cell; check the Strato Pi hardware manual for the specific battery fitted.
