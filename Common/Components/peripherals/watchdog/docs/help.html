Watchdog Misc ↓ Params ↓ Ports ↓

Watchdog controls the hardware watchdog timer present on Strato Pi and Strato Pi Max boards.

The watchdog resets the system if the kick event is not fired within the configured timeout period. Call kick periodically from your application logic (e.g. via a scheduler block) to keep the system running. The watchdog is disabled at startup and must be explicitly enabled.

read_status returns the expired flag, which is true if the watchdog fired before the last system boot (useful for distinguishing a watchdog reset from a normal boot).
