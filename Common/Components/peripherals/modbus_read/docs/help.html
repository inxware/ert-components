MODBUS Master Read Misc ↓ Params ↓ Ports ↓

This function block reads a value from a specific register in a designated device on a MODBUS network. The function block is designed to be used as a MODBUS master, which reads data from slave devices by specifying the device ID, register type, and register address. The parameters for the function block will be applied only if all required input ports are connected.
