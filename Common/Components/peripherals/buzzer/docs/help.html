Buzzer controls the piezo buzzer on Sfera Labs Iono Pi Max boards.

Fire beep with an optional freq_hz and duration_ms to play a tone. If duration_ms is 0 the tone plays continuously until stop is fired. The done event fires immediately after the sysfs write; it does not wait for the tone to finish playing.

Default frequency and duration can be set as parameters and will be used if the corresponding input ports are not connected.
