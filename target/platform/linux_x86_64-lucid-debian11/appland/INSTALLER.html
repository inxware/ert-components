eRT Debian 11 x86-64 Setup Guide

1. Install eRT on Your Desktop Open the Terminal window and follow these steps: cd ~/Downloads Download the Debian package from the link on our website or use the following command: wget https://appland.inxware.io/downloads/appland/runtimes/linux/PC-Debian-11-64bit.deb Then, install the package: sudo apt install ./PC-Debian-11-64bit.deb 3. Run eRT You can run eRT from your Applications or the terminal: /opt/ehs/bin/ehs.exe
