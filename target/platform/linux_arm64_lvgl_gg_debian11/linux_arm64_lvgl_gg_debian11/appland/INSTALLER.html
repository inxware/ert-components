eRT Raspberry Pi Setup Guide

1. Prepare Your Raspberry Pi Ensure your device is set up with Raspberry Pi OS (Legacy, 64-bit) with desktop based on Debian 11 (bullseye) You can Download software to flash your SD card from the official Raspberry Pi website at: https://www.raspberrypi.com/software/ 2. Install eRT on Your Raspberry Pi Open the Terminal window and follow these steps: cd ~/Downloads Download the Debian package from the link on our website or use the following command: wget https://appland.inxware.io/downloads/appland/runtimes/raspberrypi/RaspberryPi-Debian-11-64bit.deb Then, install the package: sudo apt install ./RaspberryPi-Debian-11-64bit.deb 3. Run eRT Or run eRT from the terminal: /opt/ehs/bin/ehs.exe
