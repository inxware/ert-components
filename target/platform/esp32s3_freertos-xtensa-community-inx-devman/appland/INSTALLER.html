Espressif Xtensa ESP32-S3 with Devman Support

1. Download the image file (Xtensa-ESP32-S3-Community.img) from the download page. 2. Install the image onto your ESP32-S3 device Launch Google Chrom or Microsoft Edge web browser.
Go to this website: https://espressif.github.io/esptool-js
 Next, connect the device via USB and allow the drivers to be installed automatically.

 Select baud-rate 460800 and click Connect.

Select the device from the list and click on Connect button.

Set the Flash Address to 0x0000, then click on Choose file button and select Xtensa-ESP32-S3-Community.img file.

Click the Program button and wait until the image is fully flashed, as shown in the screenshot below.

Once the flashing is complete, click the Disconnect button and unplug the device from your computer.
 Make sure to close (https://espressif.github.io/esptool-js) website..

 3. Configure Wi-Fi credentials on your device. The device's Wi-Fi credentials can be configured via a serial interface using open-source applications such as CuteCom: https://cutecom.sourceforge.net or a web-based serial tool like ESP Web Tools: https://esphome.github.io/esp-web-tools

 To configure Wi-Fi using ESP Web Tools, open https://esphome.github.io/esp-web-tools in Google Chrome or Microsoft Edge web browser.
 Click the connect button to open the drop-down list, select your device, and then click the connect button in the list.

Next, click the Logs & Console button to establish the connection.

Type the letter w in the console prompt, followed by the Enter key.

Follow the instructions to input your Wi-Fi SSID and password in the prompt.

 Once Wi-Fi is connected, you can type i in the prompt to check the IP address of your device to use in Lucid.

 4. (Optional) Connect the touchscreen. This device supports the ME812A, FT812 800x480 touchscreen. Use the following pin mapping to connect it:
