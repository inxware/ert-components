Arduino Mbed Nano RP2040 Connect

1. Make sure to have Arduino IDE installed on your computer.
https://www.arduino.cc/en/software.

 2. Download Arduino eRT Libary file Arduino-MBED-Nano-Community-Library.zip and improt it as a ZIP file to your IDE.

3. Open eRT example project which should be now located in 'Your PC\Documents\Arduino\libraries\eRT\examplese\RT_Project'.

4. Connect your device and add support for Arduino Mbed Nano RP2040 Connect board.

5. You will need to install following dependencies using Arduino Library Manager.

 WiFiNINA
ArduinoMqttClient
Arduino_LSM6DS3

6. Enter your WiFi credentials in the sketch and you should be good to go.
