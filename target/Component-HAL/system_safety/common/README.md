# Relevant Standards

Beyond IEC 61508, these specific standards provide detailed guidance:

- **IEC 61508-7**: Provides techniques for hardware fault avoidance and control
- **ISO 26262** (automotive): Part 5 has detailed requirements for hardware-software interaction
- **IEC 60730** (household appliances): Annex H provides specific test requirements for Class B and C software
- **EN 50128** (railway): Detailed software requirements including memory and timing
- **DO-178C** (aviation): Hardware-software interaction requirements
