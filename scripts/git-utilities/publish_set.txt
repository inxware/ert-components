# publish_set.txt — the ONLY platform targets published to the public GitHub
# mirror (github.com/inxware/ert-components).
# ── INPUT — hand-maintained. Nothing generates this file. ─────────────────────
#
# Used by:  scripts/git-utilities/publish_set.py  (and merge_into_github.sh)
#
# It also works as a regression platform list, which is how you test exactly what
# is published — run_regression.sh takes an explicit path as well as a bare name:
#   ./SystemTests/CI/run_regression.sh --platform-list scripts/git-utilities/publish_set.txt
#
# It lives here rather than in SystemTests/CI/platform-lists/ to pair with the
# tool that consumes it, and to avoid sitting next to deployed.txt — which is
# the internal regression list and means something entirely different.
#
# This is an allow-list, not a filter. A platform reaches GitHub only if it is
# named here or is pulled in as a base by one that is. Anything not listed stays
# private by default — that is the point: customer- and product-named targets
# (hrdcv2*, ambifier*, tellisign*, adnoc*, quensus*, caravan/Willerbys, heatrod,
# moodsonic, sysboiler, revolver, nxp_arm_inx_hri*/hrc*, *-sferalabs,
# *-devman-inxsystems) must never appear on GitHub.
#
# List only the platforms you want published. The sync tool resolves each one's
# `include ./target/platform/<base>/config.mk` chain and copies the bases too,
# so `./configure <target>` works on the mirror.
#
# Entry criteria — a target belongs here only if ALL hold:
#   1. Generic name: describes hardware/OS/UI stack, never a customer or product.
#   2. Its Docker image is public on Docker Hub (or ghcr.io) — see the image
#      column in docs/_working_notes/community-mirror-plan.md.
#   3. Its SDK is redistributable (no NCS nrfxlib blobs, no QNX SDP, no vendor
#      NDA toolchain).
#   4. It builds from a clean checkout with no private repo other than `apps`.
