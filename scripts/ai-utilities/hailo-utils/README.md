1. Create a python virtualenv. `python3 -m venv venv`
2. Activate the python venv. `source venv/bin/activate`
3. Download Hailo Dataflow Compiler wheel package from [https://hailo.ai/developer-zone/software-downloads/](https://hailo.ai/developer-zone/software-downloads/)
4. Install the package with `pip install ./<package>.whl`
5. Install extra package with `pip install click`
6. Run the script. See the help with `python3 tflite2jef.py --help`
