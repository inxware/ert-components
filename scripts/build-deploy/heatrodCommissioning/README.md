Backer Factory Flashing Utility for HRDx-v1 (NXP Kenetis)
==========================================================

This package can be zipped and provides a full flshing and test 
script environment for NXP Kenetid devices using JTAG methods.

The faslhing supports factory flahsing of processor boards that are 
plugged into the automatic test automation board.

Current Product
---------------
HRDI (Version 1 all display types)
HRDC (Version 1 all display types)
